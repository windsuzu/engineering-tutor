## Case shown to learner

A store dashboard must list every store, showing0 shipped orders when none exist.

### Stores

| id | name |
| --- | --- |
| 1 | North |
| 2 | South |

### Orders

| id | store_id | status |
| --- | --- | --- |
| 101 | 1 | shipped |
| 102 | 1 | shipped |
| 103 | 2 | pending |

```sql
SELECT s.name, totals.shipped_count
FROM stores AS s
LEFT JOIN (
    SELECT store_id, COALESCE(COUNT(*), 0) AS shipped_count
    FROM orders
    WHERE status = 'shipped'
    GROUP BY store_id
) AS totals ON totals.store_id = s.id
ORDER BY s.id;
```

Assumptions: exactly these rows, ordinary SQL LEFT JOIN/COUNT/COALESCE semantics, no other filters. COALESCE(x,0) returns0 if x isNULL, otherwise x.
