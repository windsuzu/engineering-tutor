## Case shown to learner

A report request calls a rendering helper. Predict the console messages from this complete program:

```java
public class ReportPreview {
    public static void main(String[] args) {
        Integer copies = null;
        System.out.println("request-start");
        try {
            generate(copies);
            System.out.println("request-done");
        } catch (NullPointerException e) {
            System.out.println("request-rejected");
        }
        System.out.println("request-end");
    }

    static void generate(Integer copies) {
        try {
            System.out.println("render-start");
            int total = copies + 1;
            System.out.println("total=" + total);
        } finally {
            System.out.println("render-cleanup");
        }
        System.out.println("render-end");
    }
}
```

Assumptions: Java21, ordinary single-threaded execution, console printing succeeds, exactly this code with no additional framework/handlers. Task: write the printed lines in order and briefly explain where normal execution stops/resumes. One focused execution-trace task; do not run the code before attempting.
