# Isolated coding assessments

Create one self-contained directory per coding assessment: `exercises/<assessment-id>/`.

Every project must include a README with purpose, linked skill IDs, pinned runtime/tool versions, prerequisites, authorized setup commands, run and test commands, known starter faults, acceptance criteria and cleanup instructions. Include starter code, automated tests and sample data without secrets. Record which checks actually ran and their results in the assessment record.

Keep projects separate from employer code and production services. Prefer local disposable services and synthetic data. Do not install dependencies without authorization. Provide no full solution before the learner's attempt. No assessment project has been started yet.
