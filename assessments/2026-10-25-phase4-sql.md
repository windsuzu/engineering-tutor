## Code

```sql
SELECT q.name,
       COUNT(*) AS joined_rows,
       COUNT(t.id) AS open_tickets
FROM queues q
LEFT JOIN tickets t
  ON t.queue_id = q.id AND t.status = 'open'
GROUP BY q.id, q.name
ORDER BY q.id;
```
